# My Shop

Це простий інтернет-магазин, створений на HTML, CSS та JavaScript.

## Функції:
- Перегляд товарів
- Кошик з анімацією
- Модальне оформлення замовлення
- Інтеграція з LiqPay (у процесі)
- Надсилання email (у процесі)
- 
AI Консультант:
Вбудований локальний AI-консультант
Користувач може взаємодіяти з магазином за допомогою голосу.

Приклад:

🎙️ «Покажи популярні товари»

🎙️ «Додай пилосос у кошик»

🎙️ «Оформи замовлення»

AI-консультант розпізнає голосові команди, виконує запит та озвучує відповідь користувачу.
